# About

My name is Landon Forney and I am developing this knowledge base as a part of my Information Organization curriculum in my Computing Applications undergraduate program.

The purpose of this knowledge base is to explain and document finanancial processes and workflows within ServiceTitan. This documentation includes invoicing, payments, job costing, accounting integrations, inventory management, and other related financial operations within the platform. This collection is intended to be a useful resources for bookkeepers, office managers, trades company owners, accountants, technical support staff, and anyone else involved in managing or troubleshooting financial operations within ServiceTitan.

This project follows a structured development/curation process:

1. Discovering quality sources
2. Evaluating the relevance and reliability of each source
3. Organizing and documenting the information in a structured manner
4. Annotating and summarizing the key information from each source
5. Synthesizing the information to create a coherent and comprehensive knowledge base
6. Continuously updating the knowledge base as new information becomes available
